# Changelog

## V2 development build — 2026-11-06
- Preserved the supplied editor's existing import, adjustment, crop, transform, history, project and export workflows.
- Added an HSL mixer with eight color ranges.
- Added clarity, sharpening approximation, film grain, temperature, tint and tonal-region controls.
- Added composition layers for text, shapes, imported images and paint strokes, including visibility, opacity, blend modes, order and basic geometry controls.
- Extended project/history snapshots to preserve supported composition layers and HSL state.
- Added arbitrary-angle rotation, image resizing, more crop ratios and wheel zoom.
- Documented roadmap items that still need a full selection/mask engine, file-format support or advanced algorithms.
